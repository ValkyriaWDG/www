Valkyria UI icon review

Sixteen original interface glyphs, extending the current 24-unit grid with 1.75-unit square-cap, miter-join strokes. Every glyph is shown at 16, 20, 24 and 32 CSS pixels on both surfaces. Use 20–24px for normal controls.

Icon asset review — not the website. No clan crest or game logos are recreated here.
