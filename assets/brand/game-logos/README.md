# Official game marks

## Hell Let Loose

The white full mark was obtained on 2026-09-29 from the navigation of the
[official Hell Let Loose game page](https://www.hellletloose.com/game/hll).
It includes the original emblem and the complete HELL LET LOOSE lettering.
The source is inline SVG in the page, not a separately licensed press-kit download.

- [Original extracted SVG](hell-let-loose-official-inline-source.svg) preserves the exact inline element.
- [Standalone SVG](hell-let-loose-fullmark-white.svg) changes only the root attribute spelling from `viewbox` to `viewBox`, which preserves standalone scaling.
- [Catalog](catalog.json) records source, dimensions, SHA-256 digests, transformations, and inspection scope.

Both files are 424 × 78 SVGs, 6,515 bytes each, with transparent backgrounds.
The artwork uses 34 paths and has no font dependency, raster image, script,
event handler, external reference, stylesheet, or embedded active content.
The normalized file was rasterized and visually inspected; transparent and
opaque alpha values were confirmed. This is asset evidence, not proof of a new UI.

Use the normalized full mark with its original aspect ratio and sufficient
contrast. Do not redraw the lettering, replace the emblem, stretch it, or
substitute the Hell Let Loose Vietnam mark. Keep an accessible game name when
using it as a meaningful image or navigation link. The original source stays
here for provenance. Both files are registered in the root asset manifest;
application placement remains separate integration work.

## Third-party boundary

The official page identifies Team17 Digital Limited in its copyright footer.
This game artwork and its trademarks are separate from Valkyria's clan mark
and are not covered by the repository's code license. The owner requested
the real game mark to identify the game on an independent community website.
No explicit general redistribution license was established from the inspected
page, and this record does not assert a trademark grant or publisher endorsement.

The existing Wardogs mark has its own provenance in
[the January 2026 press-kit catalog](../../presskit/wardogs-january-2026/catalog.json).
