# Retained Warcon game history on the Wardogs pages (2026-10-03)

Branch `feat/logi-warcon-history` (merged with main `f26c235`); captures from the local
standalone production build of `4ef415f` with the synthetic e2e fixtures and the synthetic
reader source (`LOGI_READERS_SOURCE=synthetic-fixture`: 23 labelled `[SYNTHETIC]` retained
games and 24 synthetic players validated through the same closed wire schema as a hosted
`server-game-history` read), the missing-video fallback and the local Discord mock, taken
in Chromium with Playwright (Europe/Prague, 1× pixel ratio) by
`e2e/visual-wardogs-readers.spec.ts` and `e2e/visual-admin-integrations.spec.ts`
(`CAPTURE_EVIDENCE=1`). Every image is registered in `assets/manifest.json`.

Acceptance of this slice (local synthetic proof; hosted activation stays behind an
explicit gate): the Wardogs section "Historie her serveru / Server game history" lists the
completed games Logi retained for an approved server with period, server and map filters,
faction win shares out of decided games (draws and result-less games counted separately,
with a table equivalent of the bars), a sortable player ranking behind the operator's
`publishPlayers` policy with the 60-minute default floor and coverage markers for partially
known metrics, and a paginated game history with expandable per-faction player details;
the server detail shows a compact 30-day summary; the administration integrations page
reports the history reader state; no platform ID, source ID, guild ID, source digest,
external match ID or provider server name appears in the HTML.
