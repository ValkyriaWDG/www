# Search metadata and sharing artwork

Public pages use the configured `APP_URL` origin. Czech and English homepages each
have one self-canonical, reciprocal language alternates and Czech `x-default`.
News alternates include only published translations; changing a draft never changes
the live title, URL, excerpt, artwork or structured data. Existing sitemap and private
route indexing boundaries continue to apply.

## Editorial workflow

1. Write a clear title and excerpt in the selected content language. Optional SEO
   title/description affect crawler text; the graphic uses the visible article title.
2. Choose a cover in the existing media library. Use the supplied presskit only as
   game illustration, with an appropriate source/caption. Keep original game marks
   and compositions intact. See [the presskit guide](../assets/presskit-2026-01.md).
3. Publish the selected translation explicitly. Open **Grafika pro sdílení / Sharing
   artwork** in its editor sidebar to inspect the live graphic and open its PNG.
   Saving an unpublished draft does not generate a publicly accessible preview.
4. Share the ordinary public article URL. Its Open Graph and Twitter metadata point
   to the same versioned 1200 × 630 PNG; a new published revision updates that URL.
   Social networks may retain their own cached previews. This app does not post to
   Discord or control a platform's cache.

Match graphics use the published match facts and result. Unknown scores remain
unknown; provisional results are explicitly labeled. A cancelled fixture never
displays a stale win/score. HLL articles/matches without a cover use clan artwork,
not a Wardogs scene. No fictional match result or member record is seeded.

## Templates and implementation

| Template | Public image route | Artwork |
| --- | --- | --- |
| Community | `/api/social/{cs,en}/site` | Valkyria crest + complete Flying presskit scene |
| News list | `/api/social/{cs,en}/news` | Localized NEWS/NOVINKY heading |
| Article | `/api/social/{cs,en}/news/<published-slug>` | Published title/category/date; cover or contextual fallback |
| Match list | `/api/social/{cs,en}/matches` | Localized matches heading |
| Match/result | `/api/social/{cs,en}/matches/<published-slug>` | Opponent/date/status, known score and verification label |

The layout uses the existing Barlow Condensed typeface, Valkyria crest, charcoal
panels and amber rules. Images retain their complete aspect ratio in an adjacent
panel; text does not obscure game artwork. The presskit fallback carries a localized
illustration caption. Originals are unchanged. PNGs are generated by `next/og`
from local font/image bytes; uploaded covers pass through the existing anonymous
publication-aware media delivery check. No remote URLs, arbitrary text, filesystem
paths or private previews are accepted as input.

`src/modules/social/model.ts` owns reusable card facts and bounded text;
`render.tsx` owns the composition. Long headings are bounded for the graphic only;
the full title remains in page text and metadata. The renderer supports the shipped
Latin/Czech/English glyphs; unsupported characters (including emoji) are replaced
in the graphic without fetching third-party emoji/font resources. No author identity
is inferred from an editorial label for structured data.

The Node runtime traces its local WOFF fonts into the standalone image. Its required
crest and Flying derivative already live in the registered `public/` asset set.
There are no schema migrations, new package dependencies or writable runtime paths.

## Publication and failure boundaries

Every entity image request rechecks the published DTO before using a bounded
process cache (32 cards, 30 seconds, at most two concurrent rasterizations). The
response is `no-store`; unpublishing prevents subsequent delivery even while pixels
remain in that internal cache. External copies already downloaded by a social
network cannot be revoked. Unknown/draft/scheduled/archived/wrong-locale content is
404. Storage/database/render failures are generic 503 with retry guidance; there is
no fallback that exposes private text. Requests cannot create or update content.

The specific `/api/social/` robots allow rule permits preview crawling; private APIs
remain disallowed. Image responses carry `X-Robots-Tag: noindex` to avoid treating
image endpoints as separate search documents. Published articles include escaped,
nonce-bearing `BlogPosting` JSON-LD. Search ranking and third-party unfurl rendering
are not guaranteed or claimed by these tests.
